<h1 align="center">AstrBot 中央气象署警报播报外挂</h1>

将交通部中央气象署发布的县市天气、地震、海啸、台风与其他灾害警特报，主动发送至经管理员明确登记的 AstrBot 群组。外挂使用完整 UMO（Unified Message Origin）识别目标，不绑定 QQ 或任何单一平台的私有接口。

- 版本：`0.1.2`
- 作者：`Qiuxyi_0`
- 授权条款：`AGPL-3.0-or-later`
- AstrBot 兼容版本：`>=4.26.0b10,<5`

## 功能

- 中央气象署开放数据 API 授权码为选填；未填写也能以官方 RSS 运行。
- 支持台湾 22 县市未来三个时段的天气、降雨概率、最低／最高温与舒适度。
- 支持显著有感地震、小区域有感地震、海啸、台风、豪雨／大雨、陆上强风、浓雾、高温、低温及其他天气警报。
- 每个群组可多选县市与灾害类型，并设置最多四个每日天气播报时间。
- 警报文字与台风警报单图片分开记录成功状态；图片失败不会阻断文字警报。
- 事件以官方识别数据及跨来源指纹去重，避免 API 与 RSS 切换时重复播报。
- 提供 AstrBot Plugin Page，可管理来源、群组目标、订阅规则、测试与发送记录。
- 所有外挂接口与消息均使用繁体中文；中央气象署原始内容保持官方写法。

## 播报消息格式

- 灾害警报保留发布时间、报次（若有）、影响区域、官方警报内容及官方链接；省略生效时间、到期时间与固定数据来源署名，并避免重复显示类别标题。
- 天气预报每个时段以单行呈现，包含预报时段、天气、降雨概率、温度及舒适度（依数据可用字段显示）。
- 台风警报单仍会在符合条件的新报次文字警报后另行传送；解除警报不附旧图。
- 生效与到期时间仍可由来源数据供外挂内部处理，不代表这些字段会显示在播报文字中。

## API 与 RSS 模式

| 模式 | 是否需要授权码 | 数据特性 | 适用情境 |
| --- | --- | --- | --- |
| 自动 | 选填 | 有授权码时先尝试 API；未填授权码时直接使用 RSS。API 连续三轮失败后显示「RSS 降级中」，探测成功后恢复 API | 一般建议设置 |
| 仅开放数据 API | 必填 | 使用固定数据集与结构化字段；API 不可用时不自动改用 RSS | 公开服务、商业部署或需要稳定结构化数据的环境 |
| 仅 RSS | 不需要 | 转发官方标题与摘要，不使用 LLM、不产生衍生分析 | 个人及非商业通知 |

RSS 是官方信息订阅格式，不是正式结构化 API。公开或商业部署应优先使用开放数据 API，并自行确认中央气象署最新使用条款、标示要求与数据授权范围。

## 安装

### 使用发布 ZIP

1. 解压缩 `astrbot_plugin_cwa_alert.zip`。
2. 确认解压后只有一个顶层文件夹 `astrbot_plugin_cwa_alert`。
3. 将该文件夹放入 AstrBot 的 `data/plugins/`。
4. 安装依赖套件：

   ```bash
   pip install -r data/plugins/astrbot_plugin_cwa_alert/requirements.txt
   ```

5. 重新启动 AstrBot，或在 WebUI 重新载入外挂。

### 从源代码安装

在 AstrBot 根目录执行：

```bash
git clone https://github.com/Vlxnz/astrbot_plugin_cwa_alert.git data/plugins/astrbot_plugin_cwa_alert
pip install -r data/plugins/astrbot_plugin_cwa_alert/requirements.txt
```

外挂只额外宣告 `aiohttp` 与 `Pillow`，管理页不需要 Node.js 构建或外部 CDN。

外挂总开关默认为关闭。完成群组登记与订阅设置后，仍须在管理页开启「启用自动播报」。

## 选填授权码

1. 前往[中央气象署开放数据平台](https://opendata.cwa.gov.tw/index)依官方流程申请授权码。
2. 在外挂管理页的「API 授权码（选填）」输入授权码，或在 AstrBot 执行环境设置 `CWA_API_KEY`。
3. 若在管理页输入或清除授权码，必须先保存设置，再执行「开放数据 API」来源测试；来源测试不会使用尚未保存的授权码变更。
4. `CWA_API_KEY` 环境变量优先于管理页保存的值。
5. 可在管理页执行「开放数据 API」来源测试。

未填授权码不是错误：自动模式会直接显示「RSS 模式」。管理页读取设置时只返回「是否已设置」、后四位及是否来自环境变量，不会返回完整授权码。

## 首次群组登记

1. 在需要接收播报的群组内，由 AstrBot 管理员执行：

   ```text
   /cwa_register 显示名称
   ```

2. 开启 WebUI 的外挂详情页，进入 `settings` 管理页。
3. 在「订阅规则」新增该群组，选择县市、灾害类型与天气时间。
4. 保存设置，执行测试发送，再开启全局自动播报。

外挂不会枚举机器人加入的所有群组。只有 AstrBot 管理员主动执行登记后，该完整 UMO、平台实例 ID、平台类型、群组 ID 与显示名称才会保存并出现在管理页。

## 指令

| 指令 | 权限与场景 | 用途 |
| --- | --- | --- |
| `/cwa_register [显示名称]` | AstrBot 管理员、群组内 | 登记目前群组；显示名称可省略 |
| `/cwa_unregister` | AstrBot 管理员、群组内 | 取消目前群组登记并停用对应订阅；规则会保留供日后恢复 |
| `/cwa_weather [县市]` | 一般用户 | 实时查询指定县市；省略时使用目前群组订阅的县市 |
| `/cwa_status` | 一般用户 | 显示来源模式、授权码状态、来源健康、群组登记及最近错误 |
| `/cwa_test` | AstrBot 管理员、群组内 | 通过主动发送接口向目前群组送出明确标示的测试消息 |

县市请使用官方名称，例如 `台北市`、`新北市`、`台中市`。输入常见的「台北市／台中市／台南市／台东县」时，外挂会规范化为官方「台」字。

## 管理页

管理页包含「服务状态、数据来源、群组目标、订阅规则、发送记录」五个工作区，可执行下列操作：

- 启用或停用自动播报。
- 选择自动、仅开放数据 API 或仅 RSS。
- 将警报轮询间隔设置为 60 至 600 秒，默认为 120 秒。
- 新增、更新或清除选填的 API 授权码。
- 为每个已登记群组创建最多一条订阅规则。
- 多选 22 县市、灾害类型及最多四个每日天气时间；默认时间为 `07:30`、`18:30`。
- 测试 API／RSS、预览官方内容、测试群组发送并查看最近错误。
- 经二次确认后删除群组目标；此操作会一并删除该群组的关联规则。

设置以 `revision` 防止不同管理员同时覆盖。若页面数据已过期，后端会拒绝保存或删除操作；刷新后再应用变更。

目前 AstrBot Plugin Page bridge 提供 GET 与 POST 调用，因此管理页以 `POST /settings` 与 `POST /targets/delete` 执行兼容操作。后端同时登记计划中的 `PUT /settings` 与 `DELETE /targets/<target_id>`，供支持这些方法的受验证客户端使用。

## 灾害类型

| 类型 | 播报范围 |
| --- | --- |
| 显著有感地震、小区域有感地震 | 全国性；只传送首次观察时间与官方发布时间前后五分钟内的新报告 |
| 海啸 | 全国性 |
| 台风 | 全国性 |
| 豪雨／大雨、陆上强风、浓雾、高温、低温、其他天气警报 | 依官方摘要或结构化区域与订阅县市比对 |

地方警报无法识别县市时会视为全国性消息，以降低漏报风险。新的 RSS 来源会先创建基线，不会把目前频道中的既有项目批量重播；生效中的 API 警报仍可对新订阅发送一次。

## 台风警报单

- 只有新的「海上台风警报」或「海上陆上台风警报」报次会在文字后下载官方 `I10.png`。
- 解除台风警报只发送文字，不附加可能残留的旧图。
- 下载采用 HTTPS、15 秒超时、8 MiB 上限、重定向白名单、MIME、PNG 文件头及 Pillow 解码验证。
- 新报次图片若与上一张哈希相同，文字会立即发送，图片最多等待并重试 10 分钟。
- 每个群组的文字与图片结果分开记录；同一报次部分群组图片失败时，只重试失败目标。
- 所有目标处理完成后才清理图片；外挂终止时也会清除临时 PNG 与 `.part` 文件。

官方台风页面：[台风警报](https://www.cwa.gov.tw/V8/C/P/Typhoon/TY_WARN.html)

## 调度与去重

- 时区固定为 `Asia/Taipei`（UTC+8）。
- 天气时间错过后可在 30 分钟内补发，超过时间窗不补发旧预报。
- 警报优先使用官方 ID；缺少时以类型、报次、时间、标题、区域、链接与正文 SHA-256 创建跨来源指纹。
- 文字与图片分别保存每个群组的成功状态，已成功部分不再重试。
- 已见事件与发送记录保留 30 天，最多 2,000 笔。
- 单段文字默认不超过 1,800 字，优先依段落分割。

## 平台限制

- 登记前会以 `MessageSession.from_str()` 验证完整 UMO，并确认目标是群组、平台在线且支持主动消息。
- 微信公众号与一般企业微信不支持此群组主动播报流程，会拒绝登记。
- 企业微信智能机器人的固定推送 Webhook 在同一平台实例只允许登记一个目标。
- QQ 官方平台的主动发送状态可能受重启影响；重启后请先在群内产生新消息，再执行 `/cwa_test`。
- 其他平台仍受适配器能力、机器人权限、群组状态及平台频率限制；请以管理页的目标状态与测试发送结果为准。

## 隐私

外挂只保存完成播报所需的群组识别数据、订阅设置、来源健康、事件指纹与发送结果。外挂不保存聊天内容、成员名单或一般消息记录，也不会把气象内容交给 LLM 改写。

管理页不返回完整授权码。请勿在群组、日志、Issue 或屏幕截图中公开授权码；公开 Git 仓库也不应提交 `.env`、运行期数据或含授权码的设置。

## 安全

- RSS XML 解压后上限为 2 MiB，解析前拒绝 DTD 与 ENTITY。
- API JSON、RSS 与图片均设有响应大小限制及超时。
- 台风图片的每次重新重定向都会重新检查 HTTPS、主机、端口与路径。
- 管理页不使用外部 CDN；动态字符串一律以 `textContent` 或文字节点输出。
- 后端会重新验证 revision、UMO、县市、时间、灾害类型、字段长度及重复目标。
- `CWA_API_KEY` 或后台授权码不会写入外挂日志。

## 疑难排查

### 未填授权码时无法启动

未填授权码应可正常使用。请将数据来源设为「自动」或「仅 RSS」；「仅开放数据 API」必须提供授权码。

### 管理页没有群组

确认 `/cwa_register` 是在群组内由 AstrBot 管理员执行，且指令已回复登记成功。刷新管理页后，群组才会出现在选择器。

### API 测试失败但 RSS 正常

确认授权码有效且没有多余空白，并确认 AstrBot 可连接至中央气象署开放数据平台。自动模式会在 API 连续三轮失败后降级 RSS；需要立即只用 RSS 时可手动选择「仅 RSS」。

### 没有收到主动播报

依次确认全局开关、订阅开关、群组仍已登记、灾害类型或天气时间已选择，以及平台支持主动消息。先执行 `/cwa_test` 或管理页测试发送，再查看「发送记录」与最近错误。

### 台风只有文字没有警报单

可能原因包括：事件不是海上／海陆台风警报、官方图片尚未更新、10 分钟等待已到期、图片验证失败，或平台拒绝图片。文字警报不受影响。

## 开发与测试

以下开发检查只适用于包含 `tests/` 的源代码仓库；发布 ZIP 会排除测试与 CI 文件。安装依赖套件后，可在源代码仓库的外挂根目录执行：

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
node --check pages/settings/app.js
```

测试默认完全离线，使用 `unittest` 与 `IsolatedAsyncioTestCase`。若环境已安装 Ruff，可追加：

```bash
ruff format --check .
ruff check .
```

GitHub Actions 使用 Python 3.12 执行离线测试、Python 编译检查、管理页 JavaScript 语法检查及发布 ZIP 结构检查。

| `W-C0033-005` | 高温信息 |
| `W-C0034-001` | 台风警报 |

### 官方 RSS

- [中央气象署 RSS 服务说明](https://www.cwa.gov.tw/V8/C/S/eservice/rss.html)
- 警报与特报：`https://www.cwa.gov.tw/rss/Data/cwa_warning.xml`

RSS 模式只转发官方标题与摘要，详细内容一律跳回中央气象署。RSS 格式、字段、更新频率与可用性可能由中央气象署调整；个人及非商业通知较适合使用 RSS，公开或商业服务请优先申请 API 并自行确认最新规范。
