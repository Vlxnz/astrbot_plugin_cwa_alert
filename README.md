<h1 align="center">AstrBot 中央氣象署警報播報外掛</h1>

將交通部中央氣象署發布的縣市天氣、地震、海嘯、颱風與其他災害警特報，主動傳送至經管理員明確登記的 AstrBot 群組。外掛使用完整 UMO（Unified Message Origin）識別目標，不綁定 QQ 或任何單一平台的私有介面。

- 版本：`0.1.2`
- 作者：`Qiuxyi_0`
- 授權條款：`AGPL-3.0-or-later`
- AstrBot 相容版本：`>=4.26.0b10,<5`

## 功能

- 中央氣象署開放資料 API 授權碼為選填；未填寫也能以官方 RSS 運作。
- 支援臺灣 22 縣市未來三個時段的天氣、降雨機率、最低／最高溫與舒適度。
- 支援顯著有感地震、小區域有感地震、海嘯、颱風、豪雨／大雨、陸上強風、濃霧、高溫、低溫及其他天氣警報。
- 每個群組可複選縣市與災害類型，並設定最多四個每日天氣播報時間。
- 警報文字與颱風警報單圖片分開記錄成功狀態；圖片失敗不會阻斷文字警報。
- 事件以官方識別資料及跨來源指紋去重，避免 API 與 RSS 切換時重複播報。
- 提供 AstrBot Plugin Page，可管理來源、群組目標、訂閱規則、測試與傳送紀錄。
- 所有外掛介面與訊息均使用繁體中文；中央氣象署原始內容維持官方寫法。

## 播報訊息格式

- 災害警報保留發布時間、報次（若有）、影響區域、官方警報內容及官方連結；省略生效時間、到期時間與固定資料來源署名，並避免重複顯示類別標題。
- 天氣預報每個時段以單行呈現，包含預報時段、天氣、降雨機率、溫度及舒適度（依資料可用欄位顯示）。
- 颱風警報單仍會在符合條件的新報次文字警報後另行傳送；解除警報不附舊圖。
- 生效與到期時間仍可由來源資料供外掛內部處理，不代表這些欄位會顯示在播報文字中。

## API 與 RSS 模式

| 模式 | 是否需要授權碼 | 資料特性 | 適用情境 |
| --- | --- | --- | --- |
| 自動 | 選填 | 有授權碼時先嘗試 API；未填授權碼時直接使用 RSS。API 連續三輪失敗後顯示「RSS 降級中」，探測成功後恢復 API | 一般建議設定 |
| 僅開放資料 API | 必填 | 使用固定資料集與結構化欄位；API 不可用時不自動改用 RSS | 公開服務、商業部署或需要穩定結構化資料的環境 |
| 僅 RSS | 不需要 | 轉送官方標題與摘要，不使用 LLM、不產生衍生分析 | 個人及非商業通知 |

RSS 是官方資訊訂閱格式，不是正式結構化 API。公開或商業部署應優先使用開放資料 API，並自行確認中央氣象署最新使用條款、標示要求與資料授權範圍。

## 安裝

### 使用發布 ZIP

1. 解壓縮 `astrbot_plugin_cwa_alert.zip`。
2. 確認解壓後只有一個頂層資料夾 `astrbot_plugin_cwa_alert`。
3. 將該資料夾放入 AstrBot 的 `data/plugins/`。
4. 安裝相依套件：

   ```bash
   pip install -r data/plugins/astrbot_plugin_cwa_alert/requirements.txt
   ```

5. 重新啟動 AstrBot，或在 WebUI 重新載入外掛。

### 從原始碼安裝

在 AstrBot 根目錄執行：

```bash
git clone https://github.com/Vlxnz/astrbot_plugin_cwa_alert.git data/plugins/astrbot_plugin_cwa_alert
pip install -r data/plugins/astrbot_plugin_cwa_alert/requirements.txt
```

外掛只額外宣告 `aiohttp` 與 `Pillow`，管理頁不需要 Node.js 建置或外部 CDN。

外掛總開關預設為關閉。完成群組登記與訂閱設定後，仍須在管理頁開啟「啟用自動播報」。

## 選填授權碼

1. 前往[中央氣象署開放資料平臺](https://opendata.cwa.gov.tw/index)依官方流程申請授權碼。
2. 在外掛管理頁的「API 授權碼（選填）」輸入授權碼，或在 AstrBot 執行環境設定 `CWA_API_KEY`。
3. 若在管理頁輸入或清除授權碼，必須先儲存設定，再執行「開放資料 API」來源測試；來源測試不會使用尚未儲存的授權碼變更。
4. `CWA_API_KEY` 環境變數優先於管理頁保存的值。
5. 可在管理頁執行「開放資料 API」來源測試。

未填授權碼不是錯誤：自動模式會直接顯示「RSS 模式」。管理頁讀取設定時只回傳「是否已設定」、末四碼及是否來自環境變數，不會回傳完整授權碼。

## 首次群組登記

1. 在需要接收播報的群組內，由 AstrBot 管理員執行：

   ```text
   /cwa_register 顯示名稱
   ```

2. 開啟 WebUI 的外掛詳情頁，進入 `settings` 管理頁。
3. 在「訂閱規則」新增該群組，選擇縣市、災害類型與天氣時間。
4. 儲存設定，執行測試傳送，再開啟全域自動播報。

外掛不會枚舉機器人加入的所有群組。只有 AstrBot 管理員主動執行登記後，該完整 UMO、平台實例 ID、平台類型、群組 ID 與顯示名稱才會保存並出現在管理頁。

## 指令

| 指令 | 權限與場景 | 用途 |
| --- | --- | --- |
| `/cwa_register [顯示名稱]` | AstrBot 管理員、群組內 | 登記目前群組；顯示名稱可省略 |
| `/cwa_unregister` | AstrBot 管理員、群組內 | 取消目前群組登記並停用對應訂閱；規則會保留供日後恢復 |
| `/cwa_weather [縣市]` | 一般使用者 | 即時查詢指定縣市；省略時使用目前群組訂閱的縣市 |
| `/cwa_status` | 一般使用者 | 顯示來源模式、授權碼狀態、來源健康、群組登記及最近錯誤 |
| `/cwa_test` | AstrBot 管理員、群組內 | 透過主動傳送介面向目前群組送出明確標示的測試訊息 |

縣市請使用官方名稱，例如 `臺北市`、`新北市`、`臺中市`。輸入常見的「台北市／台中市／台南市／台東縣」時，外掛會正規化為官方「臺」字。

## 管理頁

管理頁包含「服務狀態、資料來源、群組目標、訂閱規則、傳送紀錄」五個工作區，可執行下列操作：

- 啟用或停用自動播報。
- 選擇自動、僅開放資料 API 或僅 RSS。
- 將警報輪詢間隔設定為 60 至 600 秒，預設為 120 秒。
- 新增、更新或清除選填的 API 授權碼。
- 為每個已登記群組建立最多一條訂閱規則。
- 複選 22 縣市、災害類型及最多四個每日天氣時間；預設時間為 `07:30`、`18:30`。
- 測試 API／RSS、預覽官方內容、測試群組傳送並查看最近錯誤。
- 經二次確認後刪除群組目標；此操作會一併刪除該群組的關聯規則。

設定以 `revision` 防止不同管理員同時覆寫。若頁面資料已過期，後端會拒絕儲存或刪除操作；重新整理後再套用變更。

目前 AstrBot Plugin Page bridge 提供 GET 與 POST 呼叫，因此管理頁以 `POST /settings` 與 `POST /targets/delete` 執行相容操作。後端同時登記計畫中的 `PUT /settings` 與 `DELETE /targets/<target_id>`，供支援這些方法的受驗證客戶端使用。

## 災害類型

| 類型 | 播報範圍 |
| --- | --- |
| 顯著有感地震、小區域有感地震 | 全國性；只傳送首次觀察時間與官方發布時間前後五分鐘內的新報告 |
| 海嘯 | 全國性 |
| 颱風 | 全國性 |
| 豪雨／大雨、陸上強風、濃霧、高溫、低溫、其他天氣警報 | 依官方摘要或結構化區域與訂閱縣市比對 |

地方警報無法辨識縣市時會視為全國性訊息，以降低漏報風險。新的 RSS 來源會先建立基線，不會把目前頻道中的既有項目批次重播；有效中的 API 警報仍可對新訂閱傳送一次。

## 颱風警報單

- 只有新的「海上颱風警報」或「海上陸上颱風警報」報次會在文字後下載官方 `I10.png`。
- 解除颱風警報只傳送文字，不附加可能殘留的舊圖。
- 下載採 HTTPS、15 秒逾時、8 MiB 上限、重新導向白名單、MIME、PNG 檔頭及 Pillow 解碼驗證。
- 新報次圖片若與上一張雜湊相同，文字會立即傳送，圖片最多等待並重試 10 分鐘。
- 每個群組的文字與圖片結果分開記錄；同一報次部分群組圖片失敗時，只重試失敗目標。
- 所有目標處理完成後才清理圖片；外掛終止時也會清除暫存 PNG 與 `.part` 檔。

官方颱風頁面：[颱風警報](https://www.cwa.gov.tw/V8/C/P/Typhoon/TY_WARN.html)

## 排程與去重

- 時區固定為 `Asia/Taipei`（UTC+8）。
- 天氣時間錯過後可在 30 分鐘內補送，超過時間窗不補送舊預報。
- 警報優先使用官方 ID；缺少時以類型、報次、時間、標題、區域、連結與正文 SHA-256 建立跨來源指紋。
- 文字與圖片分別保存每個群組的成功狀態，已成功部分不再重試。
- 已見事件與傳送紀錄保留 30 天，最多 2,000 筆。
- 單段文字預設不超過 1,800 字，優先依段落分割。

## 平台限制

- 登記前會以 `MessageSession.from_str()` 驗證完整 UMO，並確認目標是群組、平台在線且支援主動訊息。
- 微信公眾號與一般企業微信不支援此群組主動播報流程，會拒絕登記。
- 企業微信智慧機器人的固定推送 Webhook 在同一平台實例只允許登記一個目標。
- QQ 官方平台的主動傳送狀態可能受重啟影響；重啟後請先在群內產生新訊息，再執行 `/cwa_test`。
- 其他平台仍受適配器能力、機器人權限、群組狀態及平台頻率限制；請以管理頁的目標狀態與測試傳送結果為準。

## 隱私

外掛只保存完成播報所需的群組識別資料、訂閱設定、來源健康、事件指紋與傳送結果。外掛不保存聊天內容、成員名單或一般訊息紀錄，也不會把氣象內容交給 LLM 改寫。

管理頁不回傳完整授權碼。請勿在群組、日誌、Issue 或螢幕截圖中公開授權碼；公開 Git 儲存庫也不應提交 `.env`、執行期資料或含授權碼的設定。

## 安全

- RSS XML 解壓後上限為 2 MiB，解析前拒絕 DTD 與 ENTITY。
- API JSON、RSS 與圖片均設有回應大小限制及逾時。
- 颱風圖片的每次重新導向都會重新檢查 HTTPS、主機、連接埠與路徑。
- 管理頁不使用外部 CDN；動態字串一律以 `textContent` 或文字節點輸出。
- 後端會重新驗證 revision、UMO、縣市、時間、災害類型、欄位長度及重複目標。
- `CWA_API_KEY` 或後台授權碼不會寫入外掛日誌。

## 疑難排解

### 未填授權碼時無法啟動

未填授權碼應可正常使用。請將資料來源設為「自動」或「僅 RSS」；「僅開放資料 API」必須提供授權碼。

### 管理頁沒有群組

確認 `/cwa_register` 是在群組內由 AstrBot 管理員執行，且指令已回覆登記成功。重新整理管理頁後，群組才會出現在選擇器。

### API 測試失敗但 RSS 正常

確認授權碼有效且沒有多餘空白，並確認 AstrBot 可連線至中央氣象署開放資料平臺。自動模式會在 API 連續三輪失敗後降級 RSS；需要立即只用 RSS 時可手動選擇「僅 RSS」。

### 沒有收到主動播報

依序確認全域開關、訂閱開關、群組仍已登記、災害類型或天氣時間已選擇，以及平台支援主動訊息。先執行 `/cwa_test` 或管理頁測試傳送，再查看「傳送紀錄」與最近錯誤。

### 颱風只有文字沒有警報單

可能原因包括：事件不是海上／海陸颱風警報、官方圖片尚未更新、10 分鐘等待已到期、圖片驗證失敗，或平台拒絕圖片。文字警報不受影響。

## 開發與測試

以下開發檢查只適用於包含 `tests/` 的原始碼儲存庫；發布 ZIP 會排除測試與 CI 檔案。安裝相依套件後，可在原始碼儲存庫的外掛根目錄執行：

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
node --check pages/settings/app.js
```

測試預設完全離線，使用 `unittest` 與 `IsolatedAsyncioTestCase`。若環境已安裝 Ruff，可追加：

```bash
ruff format --check .
ruff check .
```

GitHub Actions 使用 Python 3.12 執行離線測試、Python 編譯檢查、管理頁 JavaScript 語法檢查及發布 ZIP 結構檢查。

本外掛及作者不保證資料即時性、完整性、可用性或零漏報，也不對來源中斷、解析差異、平台傳送失敗、誤報、漏報，或依據播報內容採取行動所造成的直接或間接損失負責。涉及人身安全、撤離、停班停課或其他重大決策時，請同時查閱中央氣象署、國家災害防救科技中心、消防署及地方政府正式公告。
